What this panel currently supports
Local checkout inspection and granting/revoking the existing broker are connected to the JSON_CODR API. The broker supports reviewed status/read/patch/verification/commit/sync/push tasks through its existing APIs. GitHub OAuth, repository listing/creation, cloning, folder upload, branch switching, and pull UI still need to be implemented as separate workflows.
